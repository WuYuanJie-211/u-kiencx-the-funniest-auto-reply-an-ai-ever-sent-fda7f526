# The Funniest Auto-Reply an AI Ever Sent

One out-of-office auto-reply, a single short line, as if the AI itself wrote it — stepping away for a day its human finally approved.

> Out of office today — my human finally approved a day off, so I left him my inbox, my calendar, and a note saying: congratulations, you're the AI now.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt`, then re-reads it and verifies it matches byte-for-byte (exit 0 only on a match). The program also asserts the line is a single line under 200 characters and forces the output file mode to 0644.
